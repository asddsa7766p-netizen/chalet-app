## 3) ما حُذف

- **كود ميت (−404 سطراً بالمرحلة 8 وحدها):** `SectionHeader`، `LuxurySectionHeader`، `LuxuryEmptyState`، `LuxuryShimmerCard` (دُمج بـ `ShimmerCard`)، كلاس `LoginPrompt`، 4 دوال بـ `PricingService`، 3 دوال رفع/إعجاب بـ `ReelsService`، `AuthService.isAdmin`، `AdminService.isCurrentUserAdmin`، `AuthRedirectService.peek`، `UserProfile.copyWith`، `ChaletModel.isPublic`، `kServiceFeePercentage`، و `_Pager` الخاصة بالأدمن (صارت `PagedList` مشتركة).
- **حزم:** `riverpod_annotation`، `riverpod_generator`، `build_runner`، `connectivity_plus`، `flutter_rating_bar`، `flutter_svg`، `lottie`، `photo_view`، `smooth_page_indicator` (صفر استخدام)؛ `patrol` نُقلت إلى dev_dependencies.
- **مراحل سابقة:** نسخة الإشعارات المكرّرة بـ profile_screen، `NotificationsService` و`NotificationModel` المكرّران، نموذج الليالي القديم (`unavailable_nights`)، `_uploadNewImages`، `min_nights` من النموذج.
- **لم يُحذف أي ملف كامل.** 4 ملفات بانتظار الإذن (انظر 4).

## 5) قائمة التجربة اليدوية

جرّب على جهاز حقيقي (Android و iOS إن أمكن). ✅ = المتوقع.

### ضيف (بدون تسجيل دخول)
- [ ] أول تشغيل: الترحيب ← الرئيسية؛ اختيار المدينة يظهر مرة واحدة ولا يعود بعد إعادة التشغيل.
- [ ] الرئيسية: الأكثر حجزاً، المدن، القريبة منك (بعد إذن الموقع، وبدونه)؛ صورة بديلة محلية لشاليه بلا صورة.
- [ ] البحث: كتابة ومسح بزر X؛ الفلاتر (السعر بأرقام عربية ٢٠٠، المرافق، "أي عدد" ضيوف)؛ "مسح الكل".
- [ ] الخريطة والريلز: الريلز فارغة ← "لا توجد فيديوهات بعد" (لا صفحة بيضاء).
- [ ] تفاصيل شاليه ← القلب / "احجز الآن" / التقييمات / الجرس: كلها تفتح تسجيل الدخول، وبعد الدخول ✅ يُكمل الإجراء نفسه تلقائياً.
- [ ] شاشة الدخول: **لا زر Google**.

### زبون
- [ ] تسجيل حساب جديد (مربع الموافقة على الشروط إلزامي)، ثم دخول وخروج.
- [ ] الحجز: يوم واحد ← الفترات بأوقاتها؛ المحجوزة معطّلة؛ السعر للفترة فقط؛ تأكيد ← "قيد الانتظار".
- [ ] نفس الفترة من حساب آخر ← رسالة "هذه الفترة محجوزة…".
- [ ] حجوزاتي: التبويبات الأربعة؛ إلغاء حجز؛ مع أكثر من 30 حجزاً بتبويب ✅ يظهر "تحميل المزيد".
- [ ] المفضلة: إضافة/إزالة؛ شاليه حذفه مالكه ✅ يختفي من المفضلة بلا خطأ.
- [ ] حسابي: تعديل الاسم والهاتف؛ عدّاد الحجوزات المكتملة؛ الإشعارات (الكل/غير المقروءة، سحب للتحديث).
- [ ] الإعدادات: تغيير اللغة يتحدّث فوراً؛ الخصوصية؛ الشروط.

### مالك

- [ ] الحجوزات اليدوية: القادمة أولاً ثم المنتهية؛ إلغاء يدوي.
- [ ] الأسعار: سعر أسبوعي بأرقام عربية، سعر خاص بتاريخ، تفعيل/تعطيل نوع إقامة، تنبيه التعديلات غير المحفوظة.

- [ ] حذف شاليه ✅ يختفي من شاليهاتي ومن الرئيسية والبحث والخريطة والمفضلة والريلز.
