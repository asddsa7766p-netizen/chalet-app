## 3) ما حُذف

- **كود ميت (−404 سطراً بالمرحلة 8 وحدها):** `SectionHeader`، `LuxurySectionHeader`، `LuxuryEmptyState`، `LuxuryShimmerCard` (دُمج بـ `ShimmerCard`)، كلاس `LoginPrompt`، 4 دوال بـ `PricingService`، 3 دوال رفع/إعجاب بـ `ReelsService`، `AuthService.isAdmin`، `AdminService.isCurrentUserAdmin`، `AuthRedirectService.peek`، `UserProfile.copyWith`، `ChaletModel.isPublic`، `kServiceFeePercentage`، و `_Pager` الخاصة بالأدمن (صارت `PagedList` مشتركة).
- **حزم:** `riverpod_annotation`، `riverpod_generator`، `build_runner`، `connectivity_plus`، `flutter_rating_bar`، `flutter_svg`، `lottie`، `photo_view`، `smooth_page_indicator` (صفر استخدام)؛ `patrol` نُقلت إلى dev_dependencies.
- **مراحل سابقة:** نسخة الإشعارات المكرّرة بـ profile_screen، `NotificationsService` و`NotificationModel` المكرّران، نموذج الليالي القديم (`unavailable_nights`)، `_uploadNewImages`، `min_nights` من النموذج.
- **ملفات كاملة (بإذنك):** `shared_preferences_keys.dart`، `host_service.dart`، وملفا الـ export ذوا السطر الواحد (`bookings/my_bookings_screen.dart` و`reviews/reviews_screen.dart` — صارا بالمرحلة 9 الشاشتين الحقيقيتين).

## 4) ما تبقى ولماذا

| البند | السبب |
|---|---|
| ⛔ **لا رابط خارجي لسياسة الخصوصية** | المتاجر تطلب URL عاماً؛ المحتوى الحالي شاشة داخلية فقط. نص الشاشة لا يذكر الموقع الجغرافي (geolocator) ولا تقارير الأعطال (Sentry) |
| ⛔ **الشروط والأحكام نص مؤقت** | يحتاج النص الرسمي من صاحب التطبيق (الرابط بشاشة التسجيل صار يفتح الشاشة) |
| ⚠️ **المالك والأدمن لا يستطيعان حذف حسابيهما من التطبيق** | قرار الخادم: رسالة "تواصل مع الدعم" — لكن بيانات الدعم فارغة، فلا وسيلة فعلية لهما. Apple تشترط أن يتمكن **كل** مستخدم من بدء الحذف داخل التطبيق |
| بيانات الدعم (`AppStrings.supportPhone/supportEmail`) فارغة | بانتظار بياناتك؛ كل مداخل الدعم مخفية حتى تُملأ |
| `owner_add_chalet_screen.dart` لم يُقسَّم (1332 سطراً) | بعد تقسيمه فشل اختبار يقرأ **نص** الملف بمساره (لا سلوك)؛ استُرجع حسب قاعدتك. الحل: الاختبار يقرأ الملف + أجزاءه ثم يُعاد التقسيم — بانتظار موافقتك |
| بطاقة "حجوزات مؤكدة اليوم" بلوحة المالك | تحسب `الإجمالي − الملغاة` (تشمل قيد الانتظار) على المدى المختار لا "اليوم" — تسمية مضلّلة، خارج نطاق المرحلة 8 |
| عمولة المنصة 8% بإدارة الحجوزات | ثابت عرض فقط بالكود؛ يحتاج تأكيدك أنه يطابق العمولة الفعلية |
| الخريطة: حد 1000 شاليه | العلامات تحتاج المجموعة كاملة؛ سقف ثابت مقصود (7 شاليهات حالياً) |
| الدفع الإلكتروني | معطّل عمداً (`onlinePaymentEnabled = false`) لحين ربط بوابة حقيقية |

## 5) قائمة التجربة اليدوية

جرّب على جهاز حقيقي (Android و iOS إن أمكن). ✅ = المتوقع.

### ضيف (بدون تسجيل دخول)
- [ ] أول تشغيل: الترحيب ← الرئيسية؛ اختيار المدينة يظهر مرة واحدة ولا يعود بعد إعادة التشغيل.
- [ ] الرئيسية: الأكثر حجزاً، المدن، القريبة منك (بعد إذن الموقع، وبدونه)؛ صورة بديلة محلية لشاليه بلا صورة.
- [ ] البحث: كتابة ومسح بزر X؛ الفلاتر (السعر بأرقام عربية ٢٠٠، المرافق، "أي عدد" ضيوف)؛ "مسح الكل".
- [ ] الخريطة والريلز: الريلز فارغة ← "لا توجد فيديوهات بعد" (لا صفحة بيضاء).
- [ ] تفاصيل شاليه ← القلب / "احجز الآن" / التقييمات / الجرس: كلها تفتح تسجيل الدخول، وبعد الدخول ✅ يُكمل الإجراء نفسه تلقائياً.
- [ ] شاشة الدخول: **لا زر Google**.

### زبون
- [ ] تسجيل حساب جديد (مربع الموافقة على الشروط إلزامي)، ثم دخول وخروج.
- [ ] الحجز: يوم واحد ← الفترات بأوقاتها؛ المحجوزة معطّلة؛ السعر للفترة فقط؛ تأكيد ← "قيد الانتظار".
- [ ] نفس الفترة من حساب آخر ← رسالة "هذه الفترة محجوزة…".
- [ ] حجوزاتي: التبويبات الأربعة؛ إلغاء حجز؛ مع أكثر من 30 حجزاً بتبويب ✅ يظهر "تحميل المزيد".
- [ ] المفضلة: إضافة/إزالة؛ شاليه حذفه مالكه ✅ يختفي من المفضلة بلا خطأ.
- [ ] حسابي: تعديل الاسم والهاتف؛ عدّاد الحجوزات المكتملة؛ الإشعارات (الكل/غير المقروءة، سحب للتحديث).
- [ ] الإعدادات: تغيير اللغة يتحدّث فوراً؛ الخصوصية؛ الشروط.
- [ ] التسجيل: الضغط على "الشروط والأحكام" بجانب مربع الموافقة ✅ يفتح شاشة الشروط.
- [ ] حذف الحساب (الإعدادات ← الخصوصية والأمان): زر "حذف نهائياً" معطّل حتى كتابة "حذف".
  - بحجز قادم ✅ "لديك حجوزات قادمة. ألغِها أولاً ثم احذف الحساب." ويبقى الحساب.
  - بعد إلغائه ✅ "تم حذف حسابك" ← الرئيسية كضيف؛ الدخول بنفس البريد يفشل.

### مالك
- [ ] إضافة شاليه (المعالج: "السابق" وزر الرجوع يعودان خطوة) ← رسالة "بانتظار موافقة الإدارة" (لا دخول للوحة قبل الموافقة).
- [ ] بعد موافقة الأدمن: "تفعيل وضع المالك" من حسابي ← لوحة المالك **بدون إعادة تشغيل التطبيق**.
- [ ] لوحة المالك: أقرب 3 حجوزات قادمة، عدد "قيد الانتظار"، التبديل للزبون ثم العودة.
- [ ] إدارة الحجوزات: قبول/رفض (حوار تأكيد، الزر معطّل أثناء الطلب)؛ "تحميل المزيد" بعد 30.
- [ ] التقويم: شارة الفترة الجزئية؛ حجز يدوي للفترة المتاحة؛ حجب/فك حجب أيام؛ زر "اتصال" بجهاز بلا شريحة ✅ رسالة بالرقم.
- [ ] الحجوزات اليدوية: القادمة أولاً ثم المنتهية؛ إلغاء يدوي.
- [ ] الأسعار: سعر أسبوعي بأرقام عربية، سعر خاص بتاريخ، تفعيل/تعطيل نوع إقامة، تنبيه التعديلات غير المحفوظة.
- [ ] التقارير: تبديل المدى بسرعة ✅ يظهر رقم آخر مدى مختار فقط.
- [ ] حذف شاليه ✅ يختفي من شاليهاتي ومن الرئيسية والبحث والخريطة والمفضلة والريلز.
- [ ] حجز قديم لزبون حذف حسابه ✅ يظهر بإدارة الحجوزات والتقويم ولوحة المالك باسم "مستخدم محذوف" بلا هاتف ولا صورة، بلا أي خطأ.
- [ ] محاولة حذف حساب مالك له شاليه ✅ "لديك شاليهات مسجلة. تواصل مع الدعم لحذف حساب المالك."
