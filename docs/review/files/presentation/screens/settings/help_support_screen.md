### lib/presentation/screens/settings/help_support_screen.dart

- **الوظيفة:** شاشة "الدعم الفني" — 3 بطاقات معلومات تواصل (بريد إلكتروني، واتساب، أسئلة شائعة).

- **الشرح التفصيلي:** `HelpSupportScreen` (`StatelessWidget` بحت) تعرض 3 عناصر `_ContactCard` ثابتة (بريد، واتساب، FAQ)، كل واحدة بأيقونة + عنوان + نص فرعي + سهم `chevron` بنهايتها.

- **الاعتماديات:** `app_colors.dart`, `app_strings.dart` فقط. **من يستخدمه:** [profile_screen.dart](../profile/profile_screen.md) و[settings_screen.dart](settings_screen.md) (كلاهما، حسب تعليق ترويسة الملف "reused from SettingsScreen and ProfileScreen").

- **التعامل مع Supabase:** لا يوجد.

- **نقاط القوة:** بساطة التصميم، وتغليف نظيف بـ`_ContactCard` قابل لإعادة الاستخدام بصرياً.

- **الأخطاء والمخاطر المحتملة:**
  - 🟠 **متوسطة (سطر 19-35) — بطاقات تواصل تبدو تفاعلية تماماً لكنها بلا أي وظيفة إطلاقاً:** `_ContactCard` (سطر 44-103) لا تقبل حتى معامل `onTap` بتوقيعها (لا يوجد أصلاً بالكلاس) — الثلاث بطاقات جامدة تماماً. رغم ذلك، كل بطاقة تعرض `trailing: Icon(Icons.arrow_forward_ios_rounded, ...)` (سهم يوحي بصريا بأنها قابلة للنقر/التنقل) — **تضليل بصري مباشر**: المستخدم يرى سهم تنقّل قياسي (نفس النمط المستخدم بكل مكان آخر بالتطبيق لعناصر قابلة للنقر فعلياً، مثل `_menuRow` بـ[profile_screen.dart](../profile/profile_screen.md)) لكن الضغط لا يُنتج أي أثر. البريد الإلكتروني لا يفتح تطبيق البريد، رقم الواتساب لا يفتح محادثة، و"الأسئلة الشائعة" لا تنتقل لأي مكان — رغم أن `url_launcher` (المكتبة اللازمة لكل هذا) **مستخدمة بالفعل بمكانين آخرين بالمشروع** ([booking_screen.dart](../booking/booking_screen.md), [chalet_detail_screen.dart](../chalet/chalet_detail_screen.md) لمشاركة واتساب).
  - 🟠 **متوسطة (سطر 28) — رقم واتساب نائب (placeholder) حرفي معروض للمستخدم النهائي فعلياً:** `'+970 5X-XXXXXXX'` — رقم غير حقيقي بوضوح (يحتوي أحرف `X` حرفياً) لم يُستبدَل برقم دعم فعلي. لو نُشر التطبيق بهذه الحالة، يرى كل مستخدم رقماً غير صالح كأنه رقم دعم حقيقي.
  - 🟡 **بسيطة (سطر 22) — بريد إلكتروني بنطاق الاسم القديم للتطبيق:** `support@friendschalets.com` يستخدم الاسم الإنجليزي القديم "Friends Chalets" (يظهر أيضاً باسم الـwidget الجذر `FriendsChaletsApp` بـ[main.dart](../../../main.md)) بدل الاسم الحالي المعروض للمستخدم "مكان"/"Makan" — **يحتاج تأكيد**: هل هذا النطاق/البريد فعلياً مُسجَّل ومُراقَب، أم بقايا تسمية قديمة قبل تغيير اسم المنتج؟

- **اقتراح الإصلاح:**
  - إضافة `onTap` حقيقي لكل بطاقة: `url_launcher` لفتح `mailto:` للبريد و`https://wa.me/<رقم حقيقي>` للواتساب، وربط "الأسئلة الشائعة" بمحتوى فعلي (شاشة/رابط) أو إخفاؤها مؤقتاً لو لا يوجد محتوى جاهز بدل عرضها كأنها تعمل.
  - استبدال رقم الواتساب النائب برقم دعم حقيقي قبل أي نشر للإنتاج — هذه تحديداً نقطة يجب فحصها ضمن قائمة "أهم الأشياء الواجب إصلاحها قبل النشر".
  - تحديث عنوان البريد ليطابق النطاق/الهوية الفعلية الحالية للتطبيق ("مكان"/Makan) إن كان النطاق القديم غير مُستخدَم فعلياً.
